## Oi! Este é um projeto que realizei pela Rocketseat durante o evento NLW Agents. Ele consiste em um assistente de meta com IA, focado em responder perguntas sobre jogos, trazendo sugestões de builds, estratégias e decisões com base no meta atual, utilizando a API do Google Gemini. 🎮

#### O que faz?
Você escolhe o jogo, faz uma pergunta e recebe uma resposta gerada por IA com sugestões de meta, builds e estratégias.

#### Como usar
Gere sua API Key do Gemini em: https://aistudio.google.com/api-keys

Depois, no projeto, basta colar a API Key no campo indicado, escolher o jogo, fazer sua pergunta (ex: melhor build para ADC) e clicar em Perguntar.

#### Sobre a API Key
Esse projeto usa a API do Gemini (Google AI). A API Key é necessária para autenticar as requisições com a API.
OBS: Não compartilhe sua API Key publicamente.

#### Modelo da API
Atualmente (Mai/2026), o projeto utiliza o modelo gemini-2.5-flash. Caso você utilize este projeto no futuro, verifique a versão disponível do Gemini e atualize no código, se necessário.

Agora com tudo pronto, divirta-se e aproveite nos seus jogos!
